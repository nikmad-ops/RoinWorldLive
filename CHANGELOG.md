# Changelog

All material changes to the RoinWorld Live product concept and prototype are recorded here.

## [0.5] - 2026-10-22

### Added
- Full investor lifecycle: Discover -> Qualify -> Evaluate -> Apply -> Approve -> Allocate -> Document -> Fund -> Activate -> Monitor -> Verify -> Return / Exit.
- Role-based access model.
- Eligible-investor marketplace.
- Pre-investment project room.
- Project-specific investor approval and allocation workflow.
- Payment orchestration concept.
- Active Investor Project Room.
- SAP-backed financial transparency and drill-down.
- Project Intelligence and explainability.
- Project Journal, live cameras, GPS/telemetry and logistics control room.
- Waitlist and controlled exit-interest workflow.
- Contracts, insurance and external assurance layers.
- Regulator, auditor and bank oversight access.
- Blockchain-based document integrity as an infrastructure layer, not product positioning.

- Dubai Logistics Company
- Residential Development
