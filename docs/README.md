## Versioning rules

1. Product specification versions use semantic document versions: `v0.x` during prototype definition.
2. Material changes are recorded in `CHANGELOG.md`.
3. Architectural or regulatory design decisions that affect implementation are documented as ADRs.
4. Changes should be made through branches and pull requests rather than direct edits to `main`.
5. Regulatory assumptions must be marked as assumptions until confirmed by EY / the relevant regulator.
