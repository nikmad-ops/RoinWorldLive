# RoinWorld Live

RoinWorld Live is an investment operating platform for real projects.

The product combines two core experiences:

1. **Investment Marketplace** — discover eligible projects, complete onboarding, evaluate opportunities, apply, receive allocation, sign documents and fund an investment.
2. **Investment Control Platform** — after activation, monitor financial performance, project execution, operational data, risks, contracts, insurance, reporting and verified evidence.

> **Discover. Invest. Monitor. Verify.**

## Repository structure

- `docs/product/` — product concept and functional requirements
- `docs/architecture/` — platform and integration architecture
- `docs/decisions/` — Architecture Decision Records (ADR)
