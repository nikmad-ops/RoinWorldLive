# RoinWorld Live Prototype

This directory contains the clickable product prototype.

## Initial scope

The first prototype will cover:

1. Public homepage
2. Public project catalogue
3. Registration / investor classification
4. Eligible Investor Marketplace
5. Pre-Investment Project Room
6. Investment Application
7. Approval / Allocation
8. Documents / Signing
9. Payment flow
10. Investor Portfolio Dashboard
11. Full Project Investor Room
12. Financial drill-down
13. Project Health / Risks
14. Project Journal
15. Live Monitoring
16. Logistics Control Room
17. Waitlist / Exit Interest
18. Management / Compliance
19. Auditor / Regulator access

## Prototype projects

- Dubai Logistics Company
- Residential Development
- Hospital Development
- Data Center

## Deployment

- Cloudflare Workers Builds connected to `main`.
- Development domain: `dev.roinworld.live`.

## Current state

Scaffold only. No production authentication, KYC, payments, blockchain, SAP or regulatory logic is implemented yet.
